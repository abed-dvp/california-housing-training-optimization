# California Housing Training Optimization

## Goal

Understand what happens behind `.fit()` by progressively implementing
loss functions and optimization methods.

## Dataset

California Housing

20,640 observations
8 numerical input features
Regression target: MedHouseVal

## Lesson Scope

- .fit() and learned parameters
- Gradient Descent
- alternative solvers
- regression and classification loss functions
- Loss vs Metric
- Parameters vs Hyperparameters
